Existing pause, source isolation and retained exact-operation outcomes remain intact.

An actual WorkspacePanel/ImGui CPU fixture selects the camera, plays, pauses, toggles the overlay, performs a ray query and verifies collider, query and hit-marker draw data. This is not native-window or GPU evidence. The manifest maps the new local authoring behavior to these fixtures; saved FeatureWorld input is unchanged.
