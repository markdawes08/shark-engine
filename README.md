# Shark

Shark is a C++20 game engine being built for a seamless open-world MMORPG.

Built so far:

- Scene editor with hierarchy, inspector, undo/redo, viewport navigation and transform gizmos.
- Vulkan rendering and standalone scene exports.
- glTF asset imports with textures and materials.
- Jolt physics with rigid bodies, collisions, triggers and spatial queries.
- Lua scripting and editor play preview.
- Terminal tools for creating, editing and saving projects.
- Networking and persistent storage foundations.
